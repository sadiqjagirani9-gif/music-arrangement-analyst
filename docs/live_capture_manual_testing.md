# Live Audio Capture 手动测试

## 设备与录制

1. 在 Windows 本机启动服务，打开“实时捕获”。
2. 确认设备列表优先显示 `[Loopback]` 默认耳机或扬声器，同时保留麦克风输入。
3. 分别选择 48000 Hz 和 44100 Hz 录制，确认波形、电平、时长和文件大小持续变化。
4. 测试暂停：时长和文件大小应停止增长；继续后恢复增长。
5. 设置最大时长，确认到时自动停止。
6. 停止后下载 WAV，用播放器或 `wave` 工具确认 PCM16、声道和采样率。

## 分析与异常

1. 播放合法测试音频并录制，确认状态从 `processing` 进入 `analyzing` 和 `completed`。
2. 打开分析结果，确认 `source.platform=live_capture`、文件 SHA-256、报告和时间轴存在。
3. 调用 MIDI 接口，确认五个草案文件可读取。
4. 在没有声音时录制至少 2 秒，确认状态为 `invalid` 且不会创建分析任务。
5. 录制包含超过 10 秒静音的测试音频，确认验证报告标记长时间静音。
6. 录制过程中断开设备，确认状态转为 `error`，可刷新设备后重新开始。

## 版权与受保护内容

不得为了测试关闭或绕过 DRM、会员限制或播放器保护。若正常 WASAPI 输出为静音，保持原状并使用用户合法取得的本地音频文件。
